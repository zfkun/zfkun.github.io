主要记录 Winodws 环境的编译构建流程

Mac 系统参考文章, 其他系统 (Linux) 根据官方文档，适当调整即可, 较为简单

安装依赖

CMake

选择 Installer 版本, 无需额外操作:

记得勾选 Add CMake to the system PATH (命令行使用)

选择 ZIP 版本, 需手工设置环境变量:

假设解压位置: D:\toolkit\cmake\cmake-4.1.2-windows-x86_64

  1. 新建 CMAKE_HOME, 取值 D:\toolkit\cmake\cmake-4.1.2-windows-x86_64
  2. PATH 里增加一条 %CMAKE_HOME%\bin 即可

Ninja

下载 ninja-win.zip 即可, 需手工设置环境变量:

假设解压位置: D:\toolkit\ninja\ninja-win-v1.13.1

  1. 新建 NINJA_HOME, 取值 D:\toolkit\ninja\ninja-win-v1.13.1
  2. PATH 里增加一条 %NINJA_HOME%\bin 即可

Skia

注意, 这里依赖的是 Aseprite 维护的 fork 版本 (aseprite 和 laf 依赖使用)

直接下 预编译二进制包 更省事点

假设解压位置: D:\toolkit\skia\skia-m124

Visual Studio

安装 Visual Studio Community 2022 版本 的 (版本过高 的会有各种问题)

官网页面，大概率找不到 2022 社区版下载地址， 所以直接用命令行安装即可：

确保系统已安装 winget（Windows 10 1709+ 默认自带，Win11 必带）

  1. 查询可用版本列表
winget show "Microsoft.VisualStudio.2022.Community" --versions
  1. 安装指定版本

版本号不一定最新就最好 (如果遇到编译问题，可以试试用旧一点的版本)

winget install --id "Microsoft.VisualStudio.2022.Community" --version "17.14.39"

命令行环境

这里比较重要, 很多时候编译遇到各种问题，可能都是因为所处的命令行环境引起的

编译本项目，务必在 Visual Studio 自带的 x64 Native Tools Command Prompt for VS 2022 命令行终端内

位置在 C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Visual Studio 2022\Visual Studio Tools\VC\x64 Native Tools Command Prompt for VS 2022

初始化项目

直接下载工程源码

git clone --recursive https://github.com/aseprite/aseprite.git

编译构建

官方 INSTALL.md 够简洁高效了, 复制命令内容 适当调整参数 即可

cd aseprite
mkdir build
cd build

# 构建
cmake \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DLAF_WITH_EXAMPLES=OFF \
  -DLAF_WITH_TESTS=OFF \
  -DLAF_BACKEND=skia \
  -DSKIA_DIR="D:/skia/skia-m124" \
  -DSKIA_LIBRARY_DIR="D:/skia/skia-m124/out/Release-x64" \
  -DSKIA_LIBRARY="D:/skia/skia-m124/out/Release-x64/skia.lib" \
  -G Ninja \
  ..

# 编译
ninja aseprite

编译正常结束后 ./build/bin 目录下即编译产物:

  • aseprite.exe (应用程序入口)
  • data (应用依赖资源)
  • gen (没用上, 可以忽略)

到这里, 就可以直接使用了 (双击运行 ./build/bin/aseprite.exe 文件即可)

打包 ZIP

bin 目录复制到需要得地方，改名 使用即可

#aseprite #compile #app #windows
